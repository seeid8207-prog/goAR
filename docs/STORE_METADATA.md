## App name
GoAR

## Subtitle / short description
AR navigation from venue entrance to your exact seat.

## Long description
GoAR helps event attendees navigate from the outside of a venue to the exact section, row and seat. Outdoor directions use map data, while indoor routing uses venue-specific navigation graphs, checkpoints and augmented-reality guidance.

Features include:
- exact section, row and seat navigation,
- AR route guidance,
- checkpoint-based relocalization,
- automatic rerouting,
- multi-floor guidance,
- step-free route preference,
- offline venue packages for poor-connectivity environments.

Availability depends on participating venues and supported ARCore/ARKit devices.

## Permission rationale
Camera: required for augmented-reality navigation and venue checkpoint recognition.
Location: used for outdoor approach navigation to participating venues.
